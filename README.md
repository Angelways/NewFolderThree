# NewFolderThree

深層迷宮輔助插件，衍生自 [transparent-duck/NewFolder3](https://github.com/transparent-duck/NewFolder3)。

## Dalamud 自訂插件儲存庫

將以下庫鏈加入 Dalamud 的自訂插件儲存庫，再於插件安裝器搜尋 `NewFolderThree`。

```text
https://raw.githubusercontent.com/Angelways/NewFolderThree/refs/heads/main/NewFolderThree-release.json
```

歡迎提交 [Pull Request（PR）](https://github.com/Angelways/NewFolderThree/pulls)。

[版本與下載](https://github.com/Angelways/NewFolderThree/releases)
